Voice reference + multilingual dubbing demo

Record a reference. Translate and dub safely.

The repository's local OpenVoice/XTTS pipeline and Ollama setup are too heavy for a static serverless deployment. This hosted mode lets you record a reference clip, translate text, and synthesize the translated speech with the browser's installed voices. It deliberately does not claim that browser TTS is voice cloning.
